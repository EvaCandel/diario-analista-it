# Análisis de Tráfico de Red (Packet Sniffing) 🕵️‍♀️

## Descripción
Laboratorio práctico de intercepción y disección de tráfico de red en crudo utilizando `tcpdump`.

## Conceptos Aplicados y Prácticas
*   **TCP 3-Way Handshake:** Análisis del establecimiento de conexiones (banderas SYN, SYN-ACK, ACK).
*   **Filtrado Quirúrgico:** Uso de tuberías (`|`) y expresiones regulares (`grep`) para aislar datos legibles (Carga útil / Payload) entre el ruido de red.
*   **Auditoría de Protocolos:** Intercepción de peticiones HTTP en texto plano (Plaintext), demostrando la vulnerabilidad crítica de los protocolos sin cifrar frente a ataques de red pasivos.
